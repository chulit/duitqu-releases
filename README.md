# DuitQu Releases

Public release mirror for **DuitQu** — Android money tracker app.

This repository hosts the signed APKs and release notes. The source code lives in the private [chulit/duitqu](https://github.com/chulit/duitqu) repository.

## Download

Grab the latest APK from [Releases](../../releases) — pick the one matching your device's ABI:
- **arm64-v8a** — most modern phones
- **armeabi-v7a** — older 32-bit phones
- **x86_64** — emulators

Releases are signed with a permanent key, so updates install in place without uninstalling.

## In-app updates

The app checks this repository for updates (max once per day) and can download + install new versions directly.
